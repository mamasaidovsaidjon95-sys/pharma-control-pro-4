# PHARMA CONTROL PRO 4.0 — boshlang‘ich sinov

Bu **3.7 funksiyalarini saqlagan alohida 4.0 prototip**. GitHub Pages yoki HTTPS serverda PWA sifatida ochiladi, birinchi marta internet bilan ochilgandan keyin ayrim holatlarda offline ishlaydi.

**Hozir mavjud:** dorilar, omborlar, zakaz, FEFO, savdo, qaytarish, qarzdorlik, hisobot, mahalliy JSON eksport/import.

**Hali yo‘q:** haqiqiy direktor/xodim loginlari, ruxsatlar, serverdagi umumiy baza, sinxronlash, litsenziya, to‘lovlar.

**Ogohlantirish:** bu sinov, haqiqiy biznes yoki shaxsiy ma’lumotlar uchun ishlatmang. Ma’lumotlar brauzer localStorage xotirasida; boshqa qurilmada ko‘rinmaydi. 3.7 dagi ma’lumotlar avtomatik ko‘chirilmaydi; faqat tekshirilgan JSON zaxira orqali tiklash mumkin.

## Joylash
`index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg` fayllarini repozitoriy ildiziga yuklang. GitHub Pages sozlamalari alohida; Private repozitoriyda Pages imkoniyati tarifga bog‘liq bo‘lishi mumkin.
